MAJÁK vidí každý deň jasne.

Prijíma denné vstupy (prepisy, Gmail, Slack, Fathom, kalendár), rozpozná ľudí, vytiahne štruktúrované uzemnené vyhodnotenie, sleduje životný cyklus každej položky naprieč dňami a učí sa z tvojich úprav. Dva plánované behy (18:00 zavretie + 04:00 doplnenie) držia deň sviežy.

01 Prehľad

Čo MAJÁK robí

Každý vstup — plánovaný z konektora, alebo manuálny (text/súbor/obrázok) — prejde rovnakou 8-krokovou pipeline a skončí ako uzemnené položky v konkrétnom dni. Nič sa nevymýšľa, nič sa tvrdo nemaže, ľudia sa nikdy potichu nezlučujú.

18:00 · zavri & otvor zajtra

close_and_open_tomorrow

Finalizuje dnešok (snapshot + roll-up, closed), otvorí zajtrajšok, prenesie nedokončené položky (carry-over) a natiahne zajtrajší kalendár → radar + dossiere účastníkov.

04:00 · doplň noc

fill_overnight

Pre každý konektor fetch_since(cursor) → pipeline → znovu poskladá otvorený deň → pošle notifikáciu, že brief je hotový. Keď sa o 04:00 zobudíš, deň je kompletný.

Nemenné pravidlá (guardrails)

  • Uzemnenie: každá položka má doslovný citát + lokátor + zdroj.
  • Žiadne tvrdé mazanie: soft-delete + archív; zdroje navždy.
  • Žiadne potichu zlúčené osoby: neistota ide do review queue.
  • Idempotentný sync: dedup cez (connector, external_id) + kurzory.
02 Fork → Import

Rozbehni to a nalej dáta

Celý postup od forku po naplnenú databázu. Frontend (tento web) je Phase-1 tenký klient nad API.

1 · Fork & inštalácia

# fork cez GitHub UI, potom:
git clone https://github.com/<ty>/majak.git && cd majak
cp .env.example .env            # vyplň ANTHROPIC_API_KEY, SUPABASE_*
make install                    # pip install -e ".[dev,ocr]"

2 · Databáza (Supabase / Postgres + pgvector)

supabase start                  # lokálny Postgres 15 + pgvector + Storage + Auth
supabase db reset               # aplikuje supabase/migrations/* (7 migrácií, 15 tabuliek)

3 · Import dát — tri cesty

CestaPríkazKedy
Verbatim z reportu python -m majak.seed.import_report report.html --year 2026 Máš hotový HTML report (const SEED) — nahrá 76 položiek 1:1 do DB, nič sa nestratí.
Cez pipeline zo seedu python -m majak.seed.from_report report.html → make seed Vytiahne prepisy + referencie do seed/raw/ a prženie ich reálnou pipeline (LLM/heuristika).
Manuálny vstup POST /api/inputs (text · súbor · obrázok) Doplnkový vstup za behu — ide tou istou 8-krokovou pipeline.
Perzistencia: import píše do DB, na ktorú ukazuje DATABASE_URL. Pre trvalé uloženie nastav svoje Supabase. Bez ANTHROPIC_API_KEY beží extrakcia v heuristickom režime (uzemnená, ale hrubšia) — s kľúčom dostaneš kvalitu ako v reporte.

Životný cyklus dňa & carry-over day/lifecycle.py

entered_day = deň, kedy položka pribudla na tabuľu. Prenesenie vytvorí nový riadok s carry_from na predchádzajúci; koreň reťaze drží skutočný prvý deň. Prechádzaním carry_from vieš vystopovať celý reťazec: vstúpila 9.7. → prenesená → hotová 11.7. 14:32. „Všetko aktuálne" = otvorené listové položky (bez novšieho prenesenia).

Konektory connectors/

04 Kde vylepšovať

Rozširovacie body

Čisté seamy, kde vieš zasiahnuť bez búrania zvyšku:

Nový konektor

Implementuj fetch_since v connectors/ a zaregistruj. Pipeline je rovnaká.

Kvalita extrakcie

Uprav prompts/extract.py (bump verzie) alebo extraction_hints z tvojich úprav.

Zapoj embeddings

Naplň llm/embeddings.py → sémantický carry-over a dedup ožijú.

Ladenie prahov

Zmeň PERSON_MATCH_* / CARRY_THRESHOLD v configu podľa dát.

Notifikácie

Doplň kanál v scheduler/notify.py (email/Slack/push).

Frontend na API

Nahraď SEED v reporte za fetch('/api/days/current') cez frontend/api.js.

Neskôr (seamy pripravené): Jira konektor · auto-ladenie extrakcie z extraction_hints · plné web UI · mobilný push · hlasový vstup.
